# AgentHubEx 前端页面设计方案

用户账号采用全局唯一 ID，分别通过 TenantMembership 与 ProjectMembership 绑定多个租户和项目；两个层级的角色独立生效。成员页的“用户与多空间绑定”支持多选空间、分配角色、解除绑定。项目绑定必须具备所属租户成员关系，取消租户绑定会移除其下的项目绑定，其他空间关系保持不变。系统保护最后一名 owner。邀请已存在账号时复用邮箱对应的账号，不重复建用户。

顶部切换器只展示当前用户已绑定的可用空间。平台管理员管理未绑定空间的元数据，不因此获得其工作区权限。项目实际角色参与会话访问判断，A 项目的 owner 不会自动取得 B 项目的权限。所有绑定仍是内存原型，刷新重置，正式权限由后端执行。

入口：[index.html](index.html)。可直接双击打开，无需安装依赖、构建或联网。

本方案依据上一级 `多租户_agent_平台_c205364b.plan.md` 制作。它是可交互的 HTML / CSS / JavaScript 设计原型，所有数据仅保存在内存，刷新恢复初始状态。没有接入服务器、模型或真实节点；请勿输入真实密钥。

## 页面与流程

- **项目概览**：项目指标、个人待办、项目动态、运行环境与交付阶段。
- **项目看板**：固定四列与折叠取消状态；搜索、成员和优先级筛选；看板 / 列表；拖动状态、创建问题、详情、解决说明、导出 JSON。从问题创建自己的关联会话。移至评审或已解决需要人工确认和验证说明。
- **我的工作台**：仅本人会话、引擎与凭据选择、消息输入、可展开工作空间文件树、多标签代码预览、行号、文件信息、文件路径引用、个人与只读公共文件区分、关联问题、配置与公共资料上下文、权限允许 / 拒绝、会话停止与继续。会话正文区域为布局示意，实际开发继续适配 OpenCode `packages/app`，不另建会话 IDE。
- **运行实例**：远程登记表单、独占成员绑定、健康检测示例、同步组件状态、项目绑定详情。离线实例用于演示下发失败。
- **配置中心**：Agent / MCP / Skill 编辑、AGENTS.md、模型与权限布局、合并预览、草稿、不可变版本发布、目标下发、历史与回滚流程。
- **公共文件**：目录、文本预览与编辑、新建、批量上传、下载、重命名 / 移动、删除、编辑后回滚；个人工作区只读同步提示、配额与保护前缀。ZIP 解压仅说明正式后端责任。
- **成员与角色**：演示邀请、角色修改、移除确认；owner / developer / viewer 边界。
- **凭据管理**：项目 / 个人凭据元数据、添加、轮换、停用、Hub API Key 边界说明。密钥不写入数据模型或浏览器持久存储。
- **托管节点**：Phase 2 节点容量与调度页面设计；Claude 标注 Phase 3，首版不可选择。
- **审计日志**：操作元数据、动态记录、JSON 导出；不包含消息正文和凭据。
- **项目设置**：项目资料、凭据策略、组织配额、运行隔离与公共资料策略的表单设计。

## 视觉与交互约定

冷灰背景、白色卡片、蓝色主操作；绿色仅用于成功与在线状态，正文采用深灰色；侧栏负责跨模块导航，顶栏保持组织 / 项目上下文。中文界面保留必要领域名。响应式支持桌面、平板与手机；手机侧栏通过顶栏按钮展开。问题卡片可用 Enter / 空格打开；原生表单、按钮与 dialog 支持键盘操作。`⌘K` / `Ctrl+K` 打开问题搜索。

点击左下角个人菜单可切换预览角色，测试只读与管理操作拦截。角色切换是原型专用能力。前端提示不能代替正式系统中的服务端授权。

## 正式实现映射

Hub Shell 使用 SolidJS + Vite，基础组件替换为 Kobalte / Tailwind，数据表使用 TanStack Table，看板拖放替换为 solid-dnd，图标替换为 lucide-solid。此处无依赖 HTML 使用原生控件，仅承担方案评审，不是正式项目技术栈实现。

所有请求经 Hub Facade；服务端强制 tenant 与 owner 校验。远程节点地址和节点认证不能通过成员接口返回。Provider 凭据仅经写入接口提交，读取只返回元数据；会话创建时锁定凭据引用与版本。公共文件与配置分别管理，下发应在服务端执行合并、渲染、应用与校验。

## 原型范围

- 多租户 / 多项目使用内存示例数据，切换时按项目保留独立上下文，不连接真实控制平面。
- 健康检测、配置下发、权限执行与消息响应均为模拟，不会发起外部请求或运行命令。
- 设置中的凭据来源策略会影响新建会话选项；其余容量、模型、保护路径等字段主要展示产品设计，正式持久化、调度与策略执行由后端实现。
- 文件删除不实现持久回收站；上传二进制仅记录元数据，下载与预览以文本样例为主。
- 状态与数据不写入 localStorage，离开或刷新后不保留。

## 本地预览

直接打开 `index.html`，或在仓库根目录运行：

```sh
python3 -m http.server 8765 --directory .cursor/plans/html
```

然后访问 `http://localhost:8765`。停止预览按 `Ctrl+C`。

## 主视图自适应布局

- 管理页统一使用紧凑页头和可伸缩内容区；桌面主视图按视口分配高度。
- 项目看板保留四列，动态与环境改为页头入口；窄屏通过状态标签切换列。
- 设置分为基本信息、运行与凭据、公共空间、组织与配额、访问边界五个标签，表单字段仍保留在同一个表单内。
- 桌面表格按可用宽度换行，手机改为带字段名的记录卡片，避免横向拖动。
- 长列表、消息、代码和审计保留必要的局部滚动；小窗口保留纵向浏览，内容不会因强制无滚动而丢失。

## 公共文件目录树

公共文件左侧使用带展开 / 折叠、文件叶子节点、当前目录高亮与受保护标识的树形导航，支持方向键、Home / End 和 Enter。右侧路径面包屑支持返回上级。新建文件夹移入右侧工具栏，与新建文本并列；在当前目录创建子文件夹，创建后自动选中新目录。项目 docs/ 及其子目录继承受保护规则。

## Provider 连接参数

个人与项目凭据共用连接配置表单：Provider、API Key、Base URL、默认模型，以及可增删的请求 Header 键值对。Header 支持固定值与 Secret 引用。高级区域包含 Organization ID、Provider Project ID 和请求超时。Provider 切换会更新默认地址，用户填写的自定义地址保留。凭据列表的配置入口可以再次编辑这些参数；原型只在内存保存配置，不保存 API Key，不实际发送连接请求。

## 辅助信息统一置顶

所有独立的说明、策略和辅助管理块都位于主内容之前：凭据页的解析规则 / Hub API Key、实例页的项目绑定 / 双引擎说明、成员页的角色指南、节点页的隔离与调度说明、配置页的发布流程，以及公共文件页的容量 / 同步策略。弹窗内的操作按钮与全局页脚保持原有位置。

## 租户与项目管理

新增租户管理（`#tenants`）与项目管理（`#projects`）。租户页包含列表、搜索、状态筛选、创建、编辑、所有者、并发 / 磁盘 / Token 配额、启停确认和所属项目详情；需要平台管理员演示权限。项目页按当前租户列出项目，支持创建、编辑、搜索、筛选、归档 / 恢复、运行引擎与实例池、凭据策略，以及成员 / 配置 / 实例 / 文件等管理入口。

顶部空间与项目选择器现在可切换示例租户和项目。每个项目的看板、会话、公共文件、实例、项目凭据、配置与审计在内存中分别保存；用户个人凭据跨有权项目保留。新项目是独立空项目，刷新恢复初始示例。停用租户和归档项目将阻止项目功能访问，并在演示数据中停止进行中的会话。正式 RBAC、配额执行与运行时终止仍由后端实现。
